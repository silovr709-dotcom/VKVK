# Лендинг мебельного ателье «РЕцепт» (Тверь)

Конверсионная одностраничная страница, собранная по мотивам сообщества
[ВКонтакте tverkuhniru](https://vk.com/tverkuhniru) в оформлении основного
сайта ателье — того самого, что лежит в репозитории `REcept`.

Статика без сборки и зависимостей: открывается двойным щелчком по
`index.html`, публикуется на любом хостинге или на GitHub Pages.

```
index.html              разметка и весь текст страницы
assets/css/style.css    дизайн-система и вёрстка
assets/js/app.js        меню, фильтр проектов, лайтбокс, бриф, формы
assets/img/             фотографии кухонь, команды, фактур
assets/fonts/           Cormorant Garamond и Golos Text (свои, без CDN)
```

## Оформление

Почерк взят с основного сайта один в один:

- **Антиква Cormorant Garamond** в заголовках (светлое начертание, крупный
  кегль) и **Golos Text** в тексте. Оба шрифта лежат в `assets/fonts`,
  внешних запросов нет.
- **Бумажная палитра**: крем `#fffcf7`, кость `#f6f0e7`, глубокая синь
  `#13294a` вместо чёрного.
- **Золото только на линиях, цифрах и мелких надписях** — золотых кнопок,
  градиентов и «металлических» бликов нет.
- **Ноль скруглений и теней под карточками**: только волосяные разделители
  в один пиксель.
- Воздух между секциями — `clamp(4.75rem, 2.5rem + 6vw, 9.5rem)`.

## Что поменять под себя

### Название и контакты

Весь текст лежит в `index.html`. Название встречается четырежды:
в `<title>`, в логотипе шапки (`.logo__name`), в подвале (`.footer__logo`)
и в подписи (`.footer__bottom`). Телефоны — в шапке, в блоке финала и
в подвале.

> Если страница должна выходить под названием **«Тверь-кухни.ру»** —
> достаточно заменить эти четыре вхождения, больше ничего трогать не нужно.

### Куда уходят заявки

В начале `assets/js/app.js`:

```js
var LEAD_ENDPOINT = '';        // адрес, принимающий POST с JSON
var LEAD_EMAIL = 'tver-kuhni11@yandex.ru';
```

- Указан `LEAD_ENDPOINT` — заявка уходит туда (`fetch`, JSON).
- Не указан — открывается почтовый клиент с готовым письмом. Это честнее,
  чем показывать «отправлено» при отсутствии бэкенда.

JSON-заявка содержит поля `form`, `name`, `contact`, `comment`, ответы брифа
(`layout`, `priority`, `facade`, `timing`), адрес страницы и время.

### Фотографии

Файлы в `assets/img` — рабочие кадры ателье из репозитория `REcept`
(кухни, комната, фактуры). Чтобы заменить фото на новые, положите файл
с тем же именем или поправьте путь в `index.html`. Для карточек проектов
используются пары `имя.webp` и `имя@2x.webp` — вторая подставляется на
экранах с высокой плотностью пикселей.

## Запуск и публикация

Локально:

```bash
python3 -m http.server 3000
# страница на http://localhost:3000
```

GitHub Pages: в репозитории уже лежит workflow
`.github/workflows/pages.yml`. В настройках репозитория → **Pages** →
**Source: GitHub Actions** — после пуша в `main` страница соберётся сама.

Любой другой хостинг (Timeweb, Beget, Netlify, Vercel): загрузите папку
как есть, ничего собирать не нужно.
